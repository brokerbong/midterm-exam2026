01 · 이미지와 숫자

용어 → 의미 → 예시 → 입력과 출력

1–5장 자료 p.6–12

용어의미예시입력 → 출력
Pixel · 해상도픽셀은 격자의 한 위치와 그 값. 해상도는 가로×세로 위치 수.224×224 = 50,176개 위치현실 장면 → H×W 격자
RGB · Channel채널은 한 위치의 정보 축. RGB는 빨강·초록·파랑 3개 값.8-bit 채널은 0–255. RGB [165,50,140]H×W 위치 → H×W×3개 값
Tensor · Batch텐서는 다차원 수치 배열. 배치는 여러 샘플을 묶은 축.PyTorch 예: [32,3,224,224]. NCHW와 NHWC를 구분이미지 32장 → 4차원 텐서
전처리크기·채널 순서·수치 범위를 모델 입력 규칙에 맞춘다.x/255 후 (x−μ)/σ. RGB와 BGR을 확인원본 → Resize/Crop/Letterbox → 정규화 텐서
데이터 증강학습 중 의미가 유지되는 변형으로 다양한 조건을 경험시킨다.좌우 반전·회전·색 변화. 방향 표지판은 라벨 의미 확인이미지+정답 → 변형 이미지+변형 정답

이 장의 판단 기준

해상도가 높아지면 세부 정보를 담을 여지와 비용이 함께 증가한다. 흐린 사진을 확대해도 잃어버린 세부 정보가 되살아나는 것은 아니다. 학습에는 확률적 증강을 쓰고, 검증·시험에는 비교 가능한 결정적 전처리를 쓴다. Box·Mask·관절 좌표에는 이미지와 같은 기하 변환을 적용한다.

02 · 투영과 고전 비전

용어 → 의미 → 예시 → 입력과 출력

1–5장 자료 p.13–19

용어의미예시입력 → 출력
카메라 투영3D 점을 2D 이미지로 투영하며 깊이 정보 일부를 잃는다.단순 모델 x=fX/Z, y=fY/Z. Z가 2배면 투영 크기는 절반(X,Y,Z), 내부 파라미터 → (x,y)
Edge · CornerEdge는 경계를 가로지를 때 변화가 크고, Corner는 여러 방향에서 변화가 크다.직선 경계는 선을 따라 위치가 모호. 모서리는 재검출에 유리밝기 격자 → 경계 또는 특징점 위치
Keypoint · Descriptor특징점은 위치, 기술자는 주변 모양의 수치 표현.Harris·FAST는 검출기. 위치만으로 모양을 비교할 수 없다이미지 → 점 → 점 주변 벡터
SIFT · ORBSIFT는 128차원 실수 기술자, ORB는 회전 보정 이진 기술자를 사용한다.보통 SIFT는 L2 거리, ORB는 256-bit 기술자의 Hamming 거리특징점 주변 → 비교 가능한 기술자
Matching · RANSAC기술자로 후보 대응을 만든 뒤, 반복 표본 추정으로 기하적으로 일관된 대응을 찾는다.반복 창문은 잘못 매칭될 수 있다. 거리만 작다고 정답은 아니다대응 후보 → 모델+Inlier 집합
Homography평면 사이의 사영 변환. 3×3 H, 전체 스케일을 제외하면 8 자유도.p′ ∼ Hp. 일반 위치의 비퇴화 대응 최소 4쌍한 평면의 점 → 다른 영상의 대응 점

이 장의 판단 기준

Homography는 같은 평면이나 카메라 광학 중심을 고정한 순수 회전에 잘 맞는다. 깊이가 다양한 장면에서 카메라가 이동하면 시차가 생겨 하나의 H로 전부 정렬하기 어렵다. x=fX/Z는 가상 영상 평면을 쓰고 주점을 원점에 둔 단순식이며, 실제 픽셀 좌표에는 초점거리 축별 값과 주점 이동이 들어간다.

03 · CNN과 합성곱

용어 → 의미 → 예시 → 입력과 출력

1–5장 자료 p.20–27

용어의미예시입력 → 출력
CNN국소 연결·가중치 공유로 공간 패턴을 학습하는 신경망.같은 필터를 여러 위치에서 사용. 층을 쌓아 수용 영역 확대이미지 → 계층적 특징 → 예측
Convolution · Feature Map패치와 커널의 원소별 곱을 합하고 편향을 더한다.라이브러리의 일반 Conv는 커널을 뒤집지 않는 교차상관입력 특징+학습 커널 → 출력 특징 맵
Stride · PaddingStride는 이동 간격, Padding은 경계에 추가한 칸.N=5,K=3,S=1,P=1 → O=5N → floor((N+2P−K)/S)+1 (dilation=1)
Filter 수일반 합성곱에서 필터 하나는 모든 입력 채널을 보고 출력 한 채널을 만든다.입력 32×32×3, 3×3 필터 64개 → S=1,P=1이면 32×32×64C_in → C_out=필터 수
ReLUmax(0,x). 음수는 0, 양수는 유지하는 비선형 함수.[−3,0,5] → [0,0,5]. 확률로 만드는 연산은 아님활성값 → 같은 모양의 비선형 활성값
Residual Connection입력을 우회 경로로 더해 기울기 전달과 깊은 모델 학습을 돕는다.y=F(x)+x. 크기가 다르면 projection 등으로 맞춘다x와 F(x) → 같은 형상의 합

이 장의 판단 기준

Stride를 키우면 출력 공간 크기가 대체로 작아져 비용을 줄일 수 있지만 작은 물체·경계 정보가 손실될 수 있다. 필터 수를 늘리면 표현 용량과 비용이 커지지만 정확도가 보장되지는 않는다. 선형·아핀 연산만 연속해도 하나의 선형·아핀 변환으로 합쳐지므로 비선형 활성화가 필요하다.

04 · 사전학습과 전이학습

용어 → 의미 → 예시 → 입력과 출력

1–5장 자료 p.28–33

용어의미예시입력 → 출력
Representation문제 해결에 유용하도록 모델이 만든 내부 특징.비슷한 이미지 검색에 특징 벡터를 사용픽셀 → 벡터 또는 특징 맵
Pre-trained Model기존 데이터에서 학습한 가중치를 출발점으로 사용.일반 이미지 모델을 제품 불량 판별에 적응구조+학습 가중치 → 재사용 모델
Backbone · HeadBackbone은 특징 추출, Head는 작업별 결과 변환.1000종 분류 Head를 정상/불량 Head로 교체이미지 → Backbone 특징 → Head 예측
Feature ExtractionBackbone을 고정하고 새 Head만 학습.적은 데이터·유사한 도메인에서 보수적인 출발점고정 특징 → 새 작업 출력
Fine-tuningBackbone 일부 또는 전체와 Head를 새 데이터로 조정.부분 미세조정 → 필요하면 전체 해제, 검증 성능 비교기존 가중치+새 데이터 → 적응된 가중치
데이터 품질라벨 오류·누수·불균형·실환경 커버리지를 점검.같은 제품의 연속 프레임을 Train/Test에 나누면 누수 위험그룹별 데이터 분리 → 신뢰할 수 있는 평가

이 장의 판단 기준

학습할 층이 많으면 적응 능력과 과적합 위험이 함께 커진다. 학습률을 너무 높이면 기존 표현을 크게 훼손할 수 있다. 검증 세트로 설정을 선택하고 시험 세트는 최종 평가에 사용한다. Accuracy가 높아도 드문 불량을 모두 놓치면 목적을 달성하지 못한다.

05 · 탐지와 평가 지표

용어 → 의미 → 예시 → 입력과 출력

1–5장 자료 p.34–39

용어의미예시입력 → 출력
Detection객체마다 종류·사각형·신뢰도를 출력.사람 2명 → 각각 Class, Box, Score이미지 → 객체 목록
Confidence모델이 예측에 부여한 점수. 보정된 정답 확률과 같다고 보장할 수 없다.0.9라는 점수가 실제 정답률 90%라는 뜻은 아님모델 출력 → 예측 선택용 점수
IoU교집합/합집합. Box나 Mask의 겹침 정도.겹침 80, 양쪽 면적 각 100 → 80/120예측·정답 영역 → 0–1의 겹침 지표
TP · FP · FN맞춘 양성·잘못 찾은 양성·놓친 양성.탐지는 클래스 일치, IoU 기준, 정답과 일대일 대응 필요예측+정답+평가 규칙 → 오류 집계
Precision · RecallPrecision=TP/(TP+FP), Recall=TP/(TP+FN).TP=3,FP=1,FN=2 → 75%,60%집계 → 찾은 것의 정확성 / 실제 대상 포착률
AP · mAPAP는 한 클래스의 PR 곡선을 요약. mAP는 클래스별 AP 평균.AP50과 COCO AP는 다름: 후자는 IoU .50:.05:.95도 평균점수순 예측과 정답 → PR 곡선 → AP → 평균
NMS점수가 높은 Box를 남기고 많이 겹치는 낮은 점수 Box를 억제.동일 클래스의 중복 탐지 감소. 가까운 실제 객체도 억제될 수 있음중복 Box 후보 → 간추린 Box 집합

이 장의 판단 기준

신뢰도 임계값은 예측을 버릴지 결정하고, 평가 IoU 임계값은 예측 위치를 얼마나 엄격하게 채점할지 결정한다. NMS IoU 임계값은 중복 제거 강도를 결정한다. 이 세 값을 같은 의미로 해석하지 않는다. AP는 한 임계값의 Precision×Recall이 아니며, 보간·평균 방식은 평가 규약에 따른다.

06 · 분할·관절·카메라 위치

용어 → 의미 → 예시 → 입력과 출력

6장 자료 p.6–29

용어의미예시입력 → 출력
Semantic · Instance · Panoptic종류별 픽셀 / 객체별 마스크 / 배경과 개체를 포함한 전체 장면 지도.사람 두 명과 도로를 어떻게 구분하는지는 아래 비교표 확인이미지 → 픽셀 클래스·객체 ID
Encoder · Decoder인코더는 특징 추출, 디코더는 공간 해상도를 높여 픽셀 예측.출력 C×H×W 점수 → 클래스 축 argmax → H×W 클래스 맵이미지 → 압축 특징 → 픽셀별 점수
U-Net인코더의 공간 특징을 디코더로 이어 정밀한 경계 예측을 돕는다.대표 U-Net의 skip은 채널 방향 concat낮은 해상도 의미+높은 해상도 특징 → Mask
Mask R-CNNFaster R-CNN에 병렬 마스크 분기를 추가한 객체별 분할 모델.RoIAlign은 좌표 양자화로 인한 어긋남을 줄인다이미지 → Class+Box+객체별 Mask
SAM (원형)점·Box·Mask 프롬프트로 지정한 영역을 분할.같은 이미지에서는 이미지 임베딩을 재사용하고 프롬프트를 바꾼다이미지+프롬프트 → 후보 Mask+품질 예측
Human Pose관절 등 주요 점의 위치와 신뢰도 예측.COCO 예: 17개 관절의 (x,y,score). 라벨 visibility와 score는 다름사람 이미지 → 관절 좌표
Visual Localization알려진 지도에서 카메라 위치와 방향을 추정.6-DoF=이동 3+회전 3. 2D–3D 대응과 PnP 활용질의 이미지+지도+카메라 정보 → R,t

이 장의 판단 기준

Box·Mask·관절·카메라 자세는 목적과 출력이 다른 작업이다. Mask 다음에 관절, 그 다음 카메라 위치를 반드시 계산하는 직렬 단계가 아니다. 원형 SAM의 마스크만으로 클래스 이름이 자동 결정되지는 않는다. 카메라 외부 파라미터가 X_cam=R X_world+t라면 월드 좌표의 카메라 중심은 −Rᵀt이며 t 자체와 다르다.

07 · ViT와 범용 시각 표현

용어 → 의미 → 예시 → 입력과 출력

7장 자료 p.4–25

용어의미예시입력 → 출력
Patch · Embedding비겹침 패치를 펼친 뒤 학습 선형 투영으로 D차원 토큰 생성.16×16×3=768개 입력 값. D는 별도 선택하는 차원H×W×C → N×(P²C) → N×D
Position · CLS위치 임베딩은 순서/공간 정보. CLS는 분류 정보를 모으는 학습 토큰.224/16=14 → 196패치, CLS 포함 197토큰패치 임베딩+CLS+위치 → (N+1)×D
Q · K · VQ와 K로 가중치를 계산하고 V의 정보를 가중 결합.Q=XW_Q, K=XW_K, V=XW_V토큰 X → Q,K,V → 갱신 토큰
Self-Attentionsoftmax(QKᵀ/√d_k)V. 각 Query 행의 가중치 합은 1.d_k=64이면 점수를 8로 나눔. 가중치는 설명용 중요도와 항상 같지 않음T×d_k → T×T 가중치 → T×d_v
Multi-Head · Encoder여러 Head 결과를 concat·투영. Norm·Attention·MLP와 residual을 반복.ViT-B 예: D=768,12 Heads → Head당 64차원T×D → 같은 토큰 수의 문맥 특징
MAE · DINO · CLIP복원 / 다른 뷰의 자기증류 / 이미지·텍스트 정렬이라는 학습 목표 차이.모델 구조인 ViT와 학습 방법을 구분각 학습 신호 → 재사용 표현
Foundation Model대규모 사전학습 표현을 여러 작업에 재사용하는 기반 모델.분류·검색·분할 등에 Head·프롬프트·미세조정으로 적응범용 표현 → 작업별 결과

이 장의 판단 기준

패치 크기를 줄이면 공간을 더 세밀하게 나누지만 토큰 수와 전역 Attention 비용이 커진다. 정확도가 반드시 높아지는 것은 아니다. CLS는 모든 ViT 변형에 필수는 아니며 여기서는 원형 분류 ViT를 기준으로 센다. CLIP 검색에는 서로 정렬된 이미지·텍스트 인코더가 필요하며, DINO 이미지 특징을 CLIP 텍스트 특징과 바로 비교할 수는 없다.

09 · 모델은 무엇을 받아 무엇을 만드는가

고전 비전

  1. 이미지 2장
  2. Keypoint 검출: 위치 목록
  3. Descriptor: 주변 벡터
  4. 거리 비교: 대응 후보
  5. RANSAC: 일관된 대응·H
  6. Warp: 정렬 영상

RANSAC 내부: 최소 표본 선택 → 모델 추정 → 전체 대응 오차 측정 → Inlier 집계 → 반복·최선 모델 선택 → Inlier로 재추정.

CNN · 전이학습

  1. 전처리 이미지
  2. Backbone: 특징 맵
  3. Pooling 등: 특징 벡터
  4. 작업 Head: 점수
  5. 예측 클래스

새 작업에서는 Head를 바꾸고, Backbone의 고정/일부/전체 학습 여부를 검증 데이터로 선택한다.

Faster R-CNN

  1. 이미지
  2. Backbone: 공유 특징 맵
  3. RPN: 후보 Box
  4. RoI 특징 추출
  5. Class 분류+Box 보정
  6. 점수 선택·NMS: 최종 탐지

두 단계는 후보 제안과 후보별 판단이다. 이미지를 무조건 두 번 전부 처리한다는 뜻이 아니다.

YOLO · 대표적인 NMS 사용 계열

  1. 이미지
  2. Backbone/Neck: 다중 규모 특징
  3. 탐지 Head: Box·Class 점수
  4. 신뢰도 선택
  5. NMS
  6. 최종 객체 목록

별도 RPN 없이 밀집 예측한다. 구체적 Head·Anchor·NMS 사용 여부는 버전에 따라 다르다.

DETR · 원형

  1. 이미지
  2. CNN 특징+위치 정보
  3. Transformer Encoder: 문맥 특징
  4. Decoder+Object Queries: 객체 표현
  5. Class 또는 no-object + Box
  6. 객체 집합

학습 시 Hungarian Matching으로 예측과 정답을 일대일 대응한다. 원형 DETR는 NMS가 필요 없는 집합 예측을 목표로 한다. Matching은 추론 후처리가 아니다.

U-Net

  1. 이미지
  2. Encoder: 다중 해상도 특징
  3. Bottleneck: 압축 특징
  4. Upsampling+같은 규모 Encoder 특징 concat
  5. 픽셀별 클래스 점수
  6. argmax/이진 임계값: Mask

Skip은 높은 해상도의 위치 정보를 전달한다. 디코더는 원본 사진을 복사하는 것이 아니라 분할 결과를 예측한다.

Mask R-CNN

  1. 이미지
  2. Backbone/FPN: 특징
  3. RPN: 후보
  4. RoIAlign: 정렬된 고정 크기 특징
  5. 병렬 Class·Box·Mask Head
  6. 객체별 Mask와 Box

세 Head는 같은 RoI 특징에서 분기한다. 반드시 Class → Box → Mask를 차례로 계산하는 구조는 아니다.

SAM · 원형

  1. 이미지 → Image Encoder → 이미지 임베딩
  2. 프롬프트 → Prompt Encoder → 프롬프트 임베딩
  3. 두 임베딩 → Mask Decoder
  4. 후보 Mask+품질 점수

앞의 두 인코더 경로가 디코더에서 합류한다. 같은 이미지의 임베딩은 재사용 가능하며, 품질 점수는 정답 Mask 없이 모델이 추정한 값이다.

카메라 위치 추정

  1. 질의 이미지
  2. 장소 검색: 참조 이미지
  3. 특징 Matching
  4. 지도와 연결: 2D–3D 대응
  5. PnP+RANSAC
  6. 카메라 R,t

이미지 속 관절 위치가 아니라 지도 좌표계와 카메라 좌표계 사이의 변환을 구한다.

ViT · 분류

  1. 224×224×3
  2. 16×16 패치: 196개
  3. Flatten+Linear: 196×D
  4. CLS+위치: 197×D
  5. Encoder 반복: 197×D
  6. 최종 CLS → Head → 클래스

Pre-LN 블록: x → LayerNorm → MHA → x와 더함 → LayerNorm → MLP → 다시 residual 합. Self-Attention은 Encoder 안의 구성 요소다.

MAE

  1. 196패치
  2. 75% 가림: 147개
  3. 보이는 49패치 → Encoder
  4. Mask token·위치 추가 → 작은 Decoder
  5. 가린 패치 픽셀 복원 손실

49는 보이는 패치 수이며 CLS 등 보조 토큰은 별도다. 사전학습 후 복원 Decoder를 제거하고 Encoder를 작업에 활용한다.

DINO · 원형

  1. 한 이미지의 여러 뷰
  2. Student: global+local / Teacher: global
  3. 각 출력 분포
  4. Student가 Teacher 분포를 모방
  5. Student는 경사 업데이트 / Teacher는 EMA

Teacher에는 gradient를 전달하지 않는다. Centering·Sharpening 등으로 모든 입력이 같은 출력으로 붕괴하는 것을 방지한다.

CLIP · 텍스트 검색

  1. 이미지 모음 → Image Encoder → 저장 벡터
  2. 검색 문장 → 정렬된 Text Encoder → 질의 벡터
  3. 정규화 벡터 간 코사인 유사도
  4. 높은 순으로 이미지 반환

색인은 미리 계산할 수 있다. 코사인 유사도는 −1~1이며 정답 확률이 아니다.

10 · 값이 커지면 무엇이 달라지는가

바꾸는 설정과 결과 지표를 분리하기

값의 종류증가·감소의 의미조건과 예외상황에 적용
설정 · 입력 해상도 ↑위치 수·메모리·비용 ↑. 작은 대상 정보 보존 여지 ↑실제 해상도가 충분해야 유효. 단순 확대는 정보 생성이 아님작은 불량을 놓치면 원본 해상도와 처리 비용을 함께 점검
설정 · Stride ↑출력 크기 대체로 ↓, 세밀한 위치 정보 ↓다른 조건 고정. 반올림이 아닌 floor로 계산실시간 속도와 작은 객체 검출 사이의 선택
설정 · Padding ↑출력 크기가 커질 수 있고 경계 처리 범위 증가추가 0은 관측 정보가 아님. 무조건 성능 향상 아님K=3,S=1에서 P=1이면 크기 유지
설정 · 필터 수 ↑출력 채널·파라미터·비용 ↑데이터가 적으면 과적합 가능표현 용량 부족인지 데이터 문제인지 검증
설정 · 미세조정 범위/학습률 ↑가중치 변화·적응 가능성 ↑기존 표현 훼손과 과적합 위험. 학습률 효과는 단조롭지 않음검증 성능이 악화되면 범위·학습률을 줄여 비교
설정 · 신뢰도 임계값 ↑고정 예측 목록에서 남는 예측 ↓, Recall은 증가하지 않음Precision은 흔히 ↑지만 나쁜 점수 순위에서는 ↓도 가능오탐 비용이 크면 검증 PR 곡선에서 기준 선택
평가 설정 · TP 인정 IoU ↑같은 예측 위치를 더 엄격히 채점예측 Box가 바뀌는 것은 아님. 동일 평가 규약으로 비교IoU=.60 예측: .50 기준 통과, .75 기준 탈락
후처리 설정 · NMS IoU ↑겹침을 더 허용하여 억제가 느슨해짐중복이 더 남거나 가까운 실제 객체를 덜 지울 수 있음. 전체 결과는 후보 관계에 의존사람이 밀집한 장면과 중복 탐지를 함께 확인
설정 · 패치 크기 ↓패치 수 ↑, 전역 Attention의 토큰 쌍 비용 ↑공간 표현이 세밀해져도 정확도 향상 보장 없음16→8이면 패치 4배, 패치끼리 Attention 항 16배
설정 · RANSAC 오차 허용값 ↑같은 모델에서 Inlier로 인정할 대응 ↑오대응도 포함될 수 있음. 최종 모델 품질이 자동 향상하지 않음반복 창문이 많으면 느슨한 기준을 경계
지표 · Precision ↑찾았다고 한 것 중 맞는 비율 ↑Recall이 낮으면 실제 대상을 많이 놓칠 수 있음10개 찾아 10개 정답이어도 실제 100개면 Recall=10%
지표 · Recall ↑실제 양성 중 찾은 비율 ↑오탐 수는 이 값만으로 알 수 없음전부 양성이라 해도 Recall=100% 가능

11 · 계산 연습과 단계별 풀이

01 · 픽셀·텐서 값 수

224×224 RGB 32장의 값은 몇 개인가?

풀이와 정답 보기

한 장 위치=224×224=50,176. 값=50,176×3=150,528. 배치=150,528×32=4,816,896개. float32 원시 텐서는 ×4=19,267,584 bytes (약 18.38 MiB). 압축 이미지 파일 크기와 다르다.

02 · 투영

f=1000, X=1에서 Z=5와 10의 x는?

풀이와 정답 보기

x=fX/Z. 1000×1/5=200, 1000×1/10=100. X와 Z는 같은 길이 단위, f가 픽셀 단위면 x도 픽셀 단위다.

03 · 합성곱 출력 크기

N=32,K=3,P=1,S=2이면?

풀이와 정답 보기

O=floor((32+2−3)/2)+1=floor(15.5)+1=16. 정사각형이면 16×16. 입력 채널 3, 필터 64개라면 출력은 16×16×64. dilation=1 가정.

04 · 합성곱 한 칸

[10,50,90]이 3행인 패치에 [−1,0,1]이 3행인 커널을 적용하면?

풀이와 정답 보기

각 행은 10×(−1)+50×0+90×1=80. 세 행 합=240 (bias=0). 모두 50이면 각 행 합 0 → 출력 0.

05 · 필터 파라미터 수

3×3, 입력 3채널, 출력 64채널, 필터별 bias 1개라면?

풀이와 정답 보기

가중치=3×3×3×64=1,728. bias=64. 합=1,792개. 일반 dense Conv 기준. 공간 위치마다 별도 가중치를 만들지 않는다.

06 · Box IoU · 좌표

A=(0,0,100,100), B=(20,0,120,100)일 때?

풀이와 정답 보기

연속 좌표 xyxy 기준. 교집합 폭=min(100,120)−max(0,20)=80, 높이=100. I=8,000. U=10,000+10,000−8,000=12,000. IoU=2/3≈.667. 안 겹치는 축은 max(0,차이). 합집합은 일반적으로 외접 사각형 면적과 다르다.

07 · Mask IoU · Dice

정답 100px, 예측 100px, 교집합 80px라면?

풀이와 정답 보기

합집합=100+100−80=120. IoU=80/120=.667. Dice=2×80/(100+100)=.8. Dice=2IoU/(1+IoU). 양쪽이 모두 빈 경우는 분모가 0이므로 평가 규약이 필요하다.

08 · Precision · Recall · F1

TP=3, FP=1, FN=2라면?

풀이와 정답 보기

Precision=3/4=75%. Recall=3/5=60%. F1=2TP/(2TP+FP+FN)=6/9=66.7%. TN이 없어 Accuracy는 계산할 수 없다.

09 · 불균형 Accuracy

정상 900, 불량 100을 전부 정상이라고 하면?

풀이와 정답 보기

불량을 양성으로 두면 TP=0,FN=100,FP=0,TN=900. Accuracy=900/1000=90%, Recall=0/100=0%. Precision은 0/0이라 정의되지 않으며 구현이 0 등으로 처리하는 규약을 명시해야 한다.

10 · 패치·CLS 토큰

224×224를 16×16 비겹침 패치로 나누면?

풀이와 정답 보기

가로=224/16=14, 세로=14. 패치=14×14=196개. CLS 하나 추가=197개. RGB 패치 펼침=16×16×3=768개 값. D=768일 때 최종 입력은 197×768; D는 패치 개수가 아니다.

11 · 패치 크기와 Attention

패치를 16에서 8로 줄이면?

풀이와 정답 보기

패치=(224/8)²=28²=784개, CLS 포함 785. 패치만 비교하면 개수 4배·쌍 16배. CLS 포함 Attention 행렬은 197²=38,809 → 785²=616,225로 약 15.88배. 전체 실행 시간이 정확히 16배라는 뜻은 아니다.

12 · MAE 마스킹

196패치 중 75%를 가리면?

풀이와 정답 보기

가림=196×.75=147개. 보임=196−147=49개. Encoder는 보이는 패치를 처리한다. Decoder는 mask token을 추가해 복원하고 손실은 가린 패치에 계산한다. CLS는 별도로 센다.

13 · Attention 가중합

가중치 [.1,.2,.6,.1], scalar V=[1,2,3,4]라면?

풀이와 정답 보기

가중치 합=1. z=.1×1+.2×2+.6×3+.1×4=2.7. 실제 V가 벡터라면 각 성분에 같은 가중합을 적용한다. D=768, Head 12개라면 d_k=64, √d_k=8.

14 · AP · mAP

정답 2개에 예측을 점수순 TP,FP,TP로 냈다면?

풀이와 정답 보기

누적 (Recall,Precision)=(.5,1),(.5,.5),(1,2/3). 예시로 전 구간 보간 PR 적분을 쓰면 AP=.5×1+.5×(2/3)=5/6≈.833. COCO의 101점 보간 등 다른 규약에서는 수치가 달라질 수 있다. 같은 규약의 두 클래스 AP가 .8,.6이면 mAP=(.8+.6)/2=.7.

12 · 숫자를 바꿔 보는 계산실

ViT 패치 계산기

정사각형 이미지·비겹침 패치, 별도 Padding 없음. CLS 1개를 포함합니다.

그림은 최대 32×32까지만 표시하며, 계산값은 입력 전체 기준입니다.

합성곱 출력 계산기

정사각형 입력, 양쪽 동일 Padding, dilation=1. 한 변의 출력을 계산합니다.

14 · 예상 문제 32개

01 · 개념

Pixel 수와 RGB 값 수는 왜 다른가?

정답과 해설 보기

한 위치마다 RGB 3개 값이 있다. 224×224는 50,176픽셀, RGB 값은 150,528개다.

02 · 개념

전처리와 증강의 목적은?

정답과 해설 보기

전처리는 모델 입력 형식을 맞춘다. 증강은 의미가 보존되는 다양한 학습 예를 만든다. 검증에는 보통 확률적 증강을 적용하지 않는다.

03 · 개념

Edge보다 Corner가 대응 위치를 찾는 데 유리한 이유는?

정답과 해설 보기

Edge는 경계를 따라 움직여도 밝기 패턴이 비슷하지만 Corner는 여러 방향 이동에 변화가 커 위치를 구별하기 쉽다.

04 · 개념

Descriptor 거리가 가장 작으면 반드시 올바른 매칭인가?

정답과 해설 보기

아니다. 반복 무늬가 혼동을 만든다. 후보 거리의 비율 검사와 RANSAC 같은 기하 일관성 검사가 필요하다.

05 · 개념

Homography를 구하는 최소 대응 수와 조건은?

정답과 해설 보기

일반 위치의 비퇴화 점 대응 최소 4쌍. 한 평면 또는 순수 회전에 적합하며 임의 3D 이동 장면 전체를 설명하지 못할 수 있다.

06 · 개념

ReLU를 넣는 이유와 출력 범위는?

정답과 해설 보기

비선형성을 주기 위해서다. max(0,x)이므로 0 이상이며 상한이 1로 제한되지 않는다.

07 · 개념

3채널 입력에 필터 64개를 적용하면 출력 채널은?

정답과 해설 보기

일반 합성곱에서 64개. 필터 하나가 모든 입력 채널을 합해 출력 한 채널을 만든다.

08 · 개념

DETR의 Hungarian Matching은 언제 사용되는가?

정답과 해설 보기

학습 손실을 구할 때 예측 객체 집합과 정답을 일대일 대응시키는 데 사용한다. 추론 NMS 단계가 아니다.

09 · 개념

Q,K,V가 각각 하는 일은?

정답과 해설 보기

Q는 찾을 정보의 기준, K는 Q와 비교할 표현, V는 실제 가중 결합할 정보다. softmax(QKᵀ/√d_k)V로 결합한다.

10 · 개념

ViT와 Foundation Model은 같은 분류의 용어인가?

정답과 해설 보기

아니다. ViT는 구조이며 Foundation Model은 대규모 학습한 표현을 여러 작업에 재사용하는 기반 모델 개념이다.

11 · 비교

Semantic·Instance·Panoptic을 사람 2명과 도로로 설명하라.

정답과 해설 보기

Semantic은 두 사람을 같은 Person 클래스로, Instance는 두 사람을 개별 개체로, Panoptic은 두 개체와 도로 배경까지 하나의 비중첩 지도로 표현한다.

12 · 비교

Faster R-CNN과 YOLO의 핵심 차이는?

정답과 해설 보기

Faster R-CNN은 후보 제안 후 후보별 분류·보정. YOLO는 별도 RPN 없이 직접 탐지 예측. 속도·정확도 우열은 구체적 모델과 조건에 달린다.

13 · 비교

ResNet과 U-Net의 Skip 연결을 비교하라.

정답과 해설 보기

대표 ResNet은 형상을 맞춰 덧셈으로 학습을 돕고, 대표 U-Net은 Encoder 특징을 Decoder에 concat해 공간 정보를 보완한다.

14 · 비교

MAE·DINO·CLIP의 학습 정답은 어디서 오는가?

정답과 해설 보기

MAE는 가린 원본 픽셀, DINO는 다른 뷰의 Teacher 분포, CLIP은 이미지·텍스트의 올바른 쌍에서 학습 신호를 얻는다.

15 · 비교

Human Pose와 Visual Localization의 출력은?

정답과 해설 보기

Human Pose는 관절 좌표·점수. Visual Localization은 지도에 대한 카메라 위치·방향, 즉 6-DoF 자세다.

16 · 비교

CNN과 ViT 중 어느 것이 항상 정확한가?

정답과 해설 보기

항상 우수한 쪽은 없다. 구조적 가정, 사전학습, 데이터 양, 해상도, 계산 예산과 작업 조건을 함께 비교한다.

17 · 상황

Accuracy 90%, 불량 Recall 0%인 모델을 성공으로 볼 수 있는가?

정답과 해설 보기

불량 검출 목적에는 실패다. 정상 비중이 90%라면 전부 정상이라고 해도 이런 결과가 나온다.

18 · 상황

Precision은 100%인데 Recall은 10%다. 무엇을 의미하나?

정답과 해설 보기

찾았다고 한 것은 모두 맞지만 실제 대상의 90%를 놓쳤다. 점수 분포·신뢰도 기준·데이터를 확인한다.

19 · 상황

신뢰도 기준을 올리면 Precision은 반드시 올라가는가?

정답과 해설 보기

아니다. 고정 후보에서 예측 수와 Recall은 증가하지 않지만, 낮은 점수 정답을 먼저 버리면 Precision이 낮아질 수 있다.

20 · 상황

사람이 빽빽한 장면에서 NMS 기준을 높이면?

정답과 해설 보기

겹친 Box를 더 허용한다. 실제 이웃 사람을 덜 지울 여지가 있지만 중복 Box도 남을 수 있어 함께 평가한다.

21 · 상황

IoU=.6인 예측을 .5 기준에서 .75 기준으로 채점하면?

정답과 해설 보기

위치가 변한 것은 아니다. 클래스·일대일 대응을 만족해도 더 엄격한 .75 기준은 통과하지 못한다.

22 · 상황

DINO 이미지 벡터와 CLIP 텍스트 벡터의 차원이 같으면 바로 검색해도 되나?

정답과 해설 보기

안 된다. 차원이 같아도 의미 축이 정렬된 공간이 아니다. 짝지어 학습된 인코더나 별도 정렬 학습이 필요하다.

23 · 상황

모델을 크게 바꿨는데 실제 성능만 낮다면 먼저 무엇을 확인하나?

정답과 해설 보기

Train/Test 누수, 라벨 오류, 촬영 환경 차이, 클래스 불균형, 사전학습 전처리 일치를 점검한다.

24 · 상황

SAM에 같은 사진에서 다른 점을 클릭하면 무엇을 재사용하나?

정답과 해설 보기

이미지 임베딩을 재사용하고 새 프롬프트 임베딩과 Mask Decoder를 실행한다. 모델이 가리킨 영역을 분할하며 클래스 명명과는 별개다.
