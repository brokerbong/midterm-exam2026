01 · 자연어처리의 출발점

개념 · 역할 · 입력과 출력

PDF p.110–120

개념무엇이며 왜 필요한가입력 → 출력한계·헷갈리는 점
NLP · 생성형 AI · LLMNLP는 언어를 처리하는 분야, 생성형 AI는 새 데이터를 만드는 기술 범주, LLM은 대규모 언어모델이다.텍스트 → 분류·추출·번역·생성 등NLP 전체가 생성형 AI인 것은 아니며, 생성형 AI도 텍스트만 다루지는 않는다.
Token · Tokenization텍스트를 모델이 다루는 단위로 나누는 과정. 토큰은 단어·서브워드·기호 등이 될 수 있다.문장 → 토큰 목록토큰은 반드시 의미 단위가 아니며, 같은 문장도 토크나이저에 따라 개수가 달라진다.
형태소 · BPE · WordPiece형태소는 언어의 의미·문법 단위, BPE·WordPiece는 학습된 서브워드 방식이다.문장 → 서로 다른 분할 결과BPE는 빈번한 인접 쌍 병합을 사용한다. WordPiece의 ## 표시는 일부 토크나이저의 이어지는 조각 표기다.
Token ID · EmbeddingID는 어휘 항목의 번호, 임베딩은 그 항목을 나타내는 숫자 벡터다.토큰 → 정수 ID → 벡터ID 100과 101이 가깝다고 의미도 비슷한 것은 아니다.
Context Window현재 처리에 참고할 수 있는 토큰 범위의 한도. 지시·대화·문서·생성된 내용이 범위에 들어간다.지시+문서+질문 → 현재 문맥모델의 장기 기억이나 학습 데이터 크기와 다르다. 입력·출력 한도 규칙도 확인한다.
Hallucination · 한계 보완그럴듯하지만 사실과 다른 내용을 생성할 수 있다. 외부 자료 검색과 검증으로 보완한다.질문+검색 자료 → 근거를 참고한 응답RAG가 환각을 완전히 없애지는 않는다. 사설 모델·미세조정만으로 보안이 자동 보장되지 않는다.

02 · 텍스트를 숫자로 표현하기

개념 · 역할 · 입력과 출력

PDF p.1–17

개념무엇이며 왜 필요한가입력 → 출력한계·헷갈리는 점
BoW · DTMBoW는 단어의 등장 횟수로 문서를 표현한다. 문서를 행, 어휘를 열로 모으면 DTM이다.문서 → 어휘 크기의 빈도 벡터간단하고 해석하기 쉽지만 기본 Unigram BoW는 순서와 유사 의미를 직접 표현하지 못한다.
TF · df · IDFTF는 현재 문서의 빈도, df는 단어가 나온 문서 수. IDF=ln(N/df)로 희소성을 가중한다.문서 집합 → 단어별 가중치여기서는 원시 빈도 TF·자연로그·smoothing 없음. 라이브러리의 정규화·보정과 구분한다.
N-gram 언어 모델연속 N개 토큰의 패턴을 활용한다. N-gram LM은 앞의 N−1개로 다음 토큰 확률을 추정한다.앞 문맥 → 다음 토큰 확률N 증가로 더 긴 문맥을 보지만 데이터 희소성과 미관측 조합 문제가 커진다.
Perplexity정답 토큰의 평균 음의 로그확률을 지수화한 언어모델 평가 지표.정답 확률들 → PPL동일 데이터·토큰화·평가 문맥에서 낮을수록 예측에 유리. 사실 정확도를 직접 측정하지 않는다.
Sparse · Dense희소 표현은 어휘 크기의 벡터에 0이 많고, 밀집 임베딩은 학습된 실수 벡터다.단어·문서 → 벡터임베딩 각 차원에 사람이 읽을 수 있는 단일 의미가 붙는 것은 아니다.
Word2Vec · CBOW · Skip-gram비슷한 문맥에 등장하는 단어의 관계로 임베딩을 학습한다.CBOW: 주변 → 중심 / Skip-gram: 중심 → 주변정적 임베딩은 같은 어휘 항목에 같은 벡터를 주므로 다의어를 문맥별로 구분하기 어렵다.
Contextual · Sentence Embedding문맥 임베딩은 위치별 문맥을, 문장 임베딩은 문장 전체를 벡터로 표현한다.문장 → 토큰별 표현 또는 문장 벡터문장 벡터로 의미 검색을 할 수 있다. 같은 차원이어도 서로 다른 모델의 공간을 바로 비교할 수 있다고 가정하지 않는다.

03 · 순서와 기억: RNN · LSTM · GRU

개념 · 역할 · 입력과 출력

PDF p.18–34

개념무엇이며 왜 필요한가입력 → 출력한계·헷갈리는 점
Sequence · RNN순서가 의미를 가지는 데이터를 이전 상태와 현재 입력으로 처리한다.xₜ + hₜ₋₁ → hₜ각 시점마다 다른 모델을 만드는 것이 아니라 같은 가중치를 반복 사용한다.
Hidden State지금까지 처리한 정보를 담은 내부 벡터다.과거 상태+현재 토큰 → 새 상태문장 전체를 원문 그대로 저장하는 기억장치는 아니다.
BPTTRNN을 시간 순서로 펼쳐 시간 축을 따라 오차를 역전파한다.출력 손실 → 이전 시점들의 학습 신호앞 단계까지 전달되는 기울기의 크기가 안정적인지 중요하다.
장거리 의존성 · 기울기멀리 있는 정보가 필요한 관계. 반복적인 기울기 곱으로 소실·폭주가 발생할 수 있다.긴 시간 경로 → 작거나 큰 기울기문장이 길다고 항상 실패하는 것은 아니지만 장거리 학습이 어려워질 수 있다.
LSTMCell State와 Hidden State, Forget·Input·Output Gate로 정보 흐름을 조절한다.유지할 기억+새 정보 → Cell / 출력 상태기억 유지에 도움이 되지만 모든 긴 문맥 문제가 해결되지는 않는다.
GRU별도 Cell State 없이 Hidden State 중심으로 Update·Reset Gate를 사용한다.이전 상태+현재 입력 → 갱신된 상태구조가 간결해도 LSTM보다 항상 빠르거나 정확하다고 단정하지 않는다.
Sequence Labeling · BiRNN각 토큰에 라벨을 부여한다. 양방향 RNN은 앞뒤 문맥을 활용한다.토큰열 → 품사·개체명 라벨열전체 문장을 읽을 수 있는 태깅에 유리. 미래가 없는 실시간 생성과 문맥 조건이 다르다.

04 · Attention에서 Transformer까지

개념 · 역할 · 입력과 출력

PDF p.35–52 · p.46–52의 구조 그림 포함

개념무엇이며 왜 필요한가입력 → 출력한계·헷갈리는 점
Seq2Seq · 병목Encoder가 입력을 표현하고 Decoder가 출력 순서를 만든다.입력 문장 → 내부 표현 → 출력 문장기본 고정 길이 Context 하나에 긴 입력을 압축하면 세부 정보 전달이 어려울 수 있다.
Attention · Q/K/VQ는 찾는 기준, K는 비교 대상, V는 가중 결합할 정보다.QKᵀ/√dₖ → Softmax → V의 가중합가중치는 출력 시점마다 달라질 수 있다. 큰 Attention 가중치가 사실의 참·거짓을 뜻하지 않는다.
Self · Cross AttentionSelf는 같은 시퀀스에서 Q/K/V를 만들고, Cross는 Q와 K/V의 출처가 다르다.Self: 문장 내부 / Cross: 출력이 입력 참고원형 Encoder–Decoder의 Cross-Attention은 Decoder에서 Q, Encoder에서 K/V를 얻는다.
Multi-Head Attention서로 다른 학습 투영으로 여러 관계를 계산한 뒤 결합한다.여러 Head의 Attention → concat → 출력 투영Head별 역할이 ‘문법 담당’처럼 미리 고정되어 있지 않다.
Position · FFN · Add & Norm위치 정보는 순서를, FFN은 위치별 비선형 변환을 제공한다. Residual과 LayerNorm은 학습을 돕는다.임베딩+위치 → Attention → Add & Norm → FFN → Add & Norm강의의 원형 Post-LN 흐름이다. 모든 후속 모델의 블록 순서가 동일한 것은 아니다.
Causal Mask현재 위치보다 뒤의 토큰을 참고하지 못하게 한다.미래 점수 차단 → 허용된 위치의 확률Mask는 학습 정답을 미리 보는 것을 막는다. 토큰 자체를 지워 버리는 것과 다르다.
병렬 학습 · 순차 생성정답 시퀀스를 아는 학습에서는 위치별 예측을 병렬 계산할 수 있다.학습: 여러 위치 / 생성: 다음 토큰 반복일반적인 자기회귀 생성은 아직 없는 미래 토큰을 한꺼번에 알 수 없다.

05 · 사전학습 모델: BERT · GPT · T5 · BART

개념 · 역할 · 입력과 출력

PDF p.53–71

개념무엇이며 왜 필요한가입력 → 출력한계·헷갈리는 점
Pre-training · Self-supervised텍스트 자체에서 학습 목표를 만들어 언어 패턴을 배운다.대규모 텍스트 → 기본 모델사람이 모든 예제에 라벨을 달지 않는다는 뜻이며 학습 목표·정답 신호가 없다는 뜻은 아니다.
Transfer Learning미리 배운 표현·가중치를 다른 작업에 재사용한다.사전학습 모델 → 분류·추출·생성 작업새 작업의 데이터와 평가 조건에 맞는 적응이 필요하다.
BERT · Encoder-only양방향 문맥으로 토큰 표현을 만들며 대표 목표는 MLM이다.가려진 문장 → 가려진 토큰 예측분류·개체명 추출·정답 위치 찾기에 적합한 구조. 원형 BERT의 핵심을 설명한다.
GPT · Decoder-onlyCausal Self-Attention으로 앞 문맥을 보고 다음 토큰을 예측한다.앞 토큰들 → 다음 토큰 분포원형 Encoder–Decoder의 Decoder 블록을 그대로 복사한 것은 아니다. 일반적인 GPT에는 Encoder Cross-Attention이 없다.
T5 · BART · Encoder–Decoder입력을 읽고 그 입력을 바탕으로 새로운 텍스트를 만든다.입력 텍스트 → Encoder → Decoder → 출력 텍스트T5는 작업을 Text-to-Text로 통일. BART는 손상된 텍스트를 복원하는 사전학습을 사용한다.
Foundation Model넓은 데이터에서 학습한 능력을 여러 작업에 재사용하는 기반 모델 개념.대규모 학습 → 여러 작업에 적응Encoder-only 같은 구조 이름과 동일한 분류 축이 아니다.

06 · LLM의 학습과 추론

개념 · 역할 · 입력과 출력

PDF p.72–91 · 효율화 보충 p.117

개념무엇이며 왜 필요한가입력 → 출력한계·헷갈리는 점
Model · Data · Compute파라미터·학습 토큰·계산 자원의 균형으로 규모를 확장한다.정제·중복 제거·구성 조정한 데이터 → 학습모델이나 데이터의 양만 증가시켜 성능 향상을 보장할 수 없다.

Temperature · Top-k · Top-pTemperature는 확률 모양, Top-k·Top-p는 후보 범위를 조절한다.점수와 설정 → 후보 확률 → 선택다양성과 사실 정확도는 별개다. 동시에 적용할 때 처리 순서와 구현 규칙을 확인한다.
Few-shot · In-context Learning프롬프트의 지시·예시를 참고해 작업을 수행한다.지시+예시+질문 → 응답일반적인 추론에서 모델 가중치를 업데이트하는 학습은 아니다.

지표무엇을 측정좋은 방향비교 조건그 값만으로 모르는 것
평가 NLL / Cross-Entropy정답 토큰에 준 확률의 음의 로그 평균작을수록 정답 예측에 유리같은 테스트·토큰화·손실 대상·문맥Train Loss만 감소하면 과적합일 수 있다. 서로 다른 SFT 마스킹 규칙의 값은 직접 비교하지 않는다.

작업 정확도해당 평가에서 맞힌 비율정해진 작업·데이터에서는 높을수록 좋음같은 테스트·정답 기준·클래스 구성불균형 데이터에서 일부 유형을 놓쳐도 높을 수 있다. 유형별 결과도 본다.
형식 준수율요구한 JSON·분류 코드 등 형식을 지킨 비율높을수록 형식에 잘 맞음같은 스키마·검사 기준형식이 맞아도 내용은 틀릴 수 있다.
사실성 · 환각률주장의 근거 일치 또는 잘못된 주장 비율사실성 ↑ / 같은 정의의 환각률 ↓근거·채점 규칙·분모·응답 대상짧게 답하거나 회피해도 비율이 변한다. 답변의 유용성과 함께 본다.
지연시간 · TTFT요청 완료 시간 또는 첫 토큰까지 시간같은 조건에서 짧으면 반응이 빠름입출력 길이·하드웨어·동시 요청·측정 구간첫 토큰이 빨라도 긴 답변의 완료는 느릴 수 있다.

평가 지표로 오해하기 쉬운 값

TF-IDF는 문서 안 단어의 가중치, Attention Weight는 정보 결합 가중치, Logit은 후보 점수다. 높아졌다고 모델 전체의 성능이 좋아졌다는 뜻이 아니다. Temperature·Top-p는 결과 점수가 아니라 생성 설정이다.

TF-IDF: df가 10 → 50으로 늘면?

PDF p.7 · 수치 보충

N=100, TF=3 고정. 자연로그, smoothing·정규화 없음.

① df=10: IDF=ln(10)≈2.303 → TF-IDF≈6.908. ② df=50: IDF=ln(2)≈0.693 → TF-IDF≈2.079. 더 많은 문서에 나오는 단어이므로 구분 가중치가 줄어든다.

Bigram 확률

PDF p.8–9 · 계산 보충

앞 토큰 ‘오늘’의 다음 토큰 관측이 총 20회, ‘날씨’가 5회.

평활화 없는 빈도 추정 P(날씨|오늘)=5/20=0.25. 미관측 다음 토큰은 0이 될 수 있으므로 데이터 희소성이 문제다.

Softmax와 가중합

PDF p.41–43 · Value 수치 보충

Score=[2,1,0], scalar Value=[10,20,30].

① exp 점수를 합으로 나눔 → [0.66524,0.24473,0.09003]. ② 0.66524×10+0.24473×20+0.09003×30≈14.248. 최대 점수의 Value만 선택하는 연산이 아니다.

Head 차원과 Scale

PDF p.43, 46 · 계산 보충

모델 차원 D=512, Head=8, 동일 분할.

dₖ=512/8=64, 점수는 √64=8로 나눈다. Head=16이면 dₖ=32다. D를 고정했으므로 Head 수를 두 배로 늘린다고 전체 표현 차원도 두 배가 되지는 않는다.

정답 확률과 Loss

PDF p.76

정답 확률이 0.3 → 0.9로 변함.

−ln(0.3)≈1.204 → −ln(0.9)≈0.105. 이 정답 토큰의 손실은 감소. 학습 전체나 새 데이터 성능 향상까지 단정할 수 없다.

PPL: 두 정답 토큰의 확률

PDF p.10 · 정의와 계산 보충

확률이 [0.5,0.25], 두 토큰을 동일 비중 평가.

평균 NLL=−(ln0.5+ln0.25)/2≈1.040. PPL=exp(1.040)≈2.828. 1/평균 확률=2.667과 다르다. 기하평균 확률의 역수다.

입력 길이와 Attention 점수 수

PDF p.81 · 수치 보충

실제 길이가 1,024 → 2,048, Head 하나의 표준 Full Attention.

1,024²=1,048,576 → 2,048²=4,194,304개, 4배. 주요 쌍별 계산의 비율이며 전체 실행 시간·전체 메모리가 정확히 4배라는 뜻은 아니다.

Top-k와 Top-p

PDF p.90 · 재정규화 보충

확률 [0.45,0.30,0.15,0.07,0.03]. 각각 독립 적용.

Top-k=2: A,B 유지 → 재정규화 [0.6,0.4]. Top-p=0.8: A+B=0.75로 부족하므로 C까지 유지 → [0.5,0.3333,0.1667].

LoRA의 학습 파라미터

PDF p.100 · 계산 보충

W: 4,096×4,096, rank r=8. 한 행렬의 A/B만 계산.

W는 16,777,216개. A/B는 r(k+d)=8×8,192=65,536개, 원래 W의 0.390625%. r=16이면 131,072개로 2배. 기본 W 저장 메모리는 여전히 필요하다.

가중치 저장량과 양자화

PDF p.101–103 · 계산 보충

파라미터 10억 개, 순수 가중치 저장량, decimal GB.

16-bit: 10⁹×16/8=2GB. 4-bit: 0.5GB로 1/4. 파라미터 수는 그대로. 실제 실행 메모리는 양자화 메타데이터·Cache·활성값 등 때문에 더 크다.

바꾸는 설정값
