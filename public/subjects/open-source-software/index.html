01 오픈소스·리눅스 기초

오픈소스의 기준

기반: 중간평가 예상문제 1–4, 26–27 / 설치·기본 명령 문제

소스 코드 공개와 라이선스에 따른 사용·수정·재배포 권한을 함께 본다. 무료 여부만으로 판단하지 않는다. Linux, Apache HTTP Server, Python, Git은 대표적인 예다.

커널·셸·운영체제 환경

기반: 중간평가 예상문제 1–4, 26–27 / 설치·기본 명령 문제

커널은 하드웨어 자원과 프로세스를 관리한다. 셸은 입력한 명령을 해석한다. CLI는 명령줄, GUI는 그래픽 인터페이스다. Windows에서 VMware로 Ubuntu를 실행하면 Windows가 호스트, Ubuntu가 게스트다.

확인 대상 구분

기반: 중간평가 예상문제 1–4, 26–27 / 설치·기본 명령 문제

whoami → 현재 유효 사용자 이름 / pwd → 현재 작업 디렉터리 / hostname → 호스트 이름 / history → 명령 이력. 설치 미디어 이미지의 대표 확장자는 .iso다.

02 경로·파일·디렉터리

현재 위치와 목록

기반: 중간평가 예상문제 4–10 / 기본 명령 연결 문제

pwd는 위치 출력, cd는 위치 변경이다. cd ..는 부모, cd ~는 홈으로 이동한다. ls -a는 숨김 항목을 포함하고 ls -l은 상세 정보를 표시한다. ls -al은 두 옵션을 결합한다.

생성·복사·이동

기반: 중간평가 예상문제 4–10 / 기본 명령 연결 문제

mkdir은 디렉터리를 만들고 mkdir -p는 중간 경로도 만든다. touch는 새 빈 파일 생성 또는 기존 파일의 시각 갱신이다. cp는 복사, mv는 이동·이름 변경이다. cp -r은 디렉터리 내부까지 복사한다. 대상 경로가 기존 디렉터리인지에 따라 결과 경로가 달라진다.

조회·삭제

기반: 중간평가 예상문제 4–10 / 기본 명령 연결 문제

cat은 내용 출력, head는 기본 첫 10줄, less는 페이지 단위 조회, file은 파일 유형 판별, clear는 화면 정리다. rm은 파일 삭제, rm -r은 디렉터리 내부까지 삭제, rmdir은 빈 디렉터리 삭제다.

옵션과 결과를 따로 읽기

기반: 중간평가 예상문제 4–10 / 기본 명령 연결 문제

cp -r lab backup에서 바꾸는 값은 옵션·원본·목적지다. 확인할 결과는 원본 보존 여부와 새 경로다. touch의 결과는 파일 존재 여부에 따라 다르며, 기존 내용을 비우는 명령으로 외우지 않는다.

03 자동완성·이력·nano·vi

자동완성과 이력

기반: 학습지 3–4쪽 / 중간평가 예상문제 13–15

Bash에서 Tab은 명령·파일 이름 완성에 사용한다. 후보가 여러 개면 더 입력하거나 Tab을 두 번 눌러 후보를 확인한다. ↑는 이전 명령, ↓는 이력 탐색 중 다음 명령이다. history는 이력을 출력하며 불러온 명령은 실행 전에 수정할 수 있다.

nano 저장 흐름

기반: 학습지 3–4쪽 / 중간평가 예상문제 13–15

nano memo.txt → 입력 → Ctrl+O → Enter로 파일 이름 확인 → Ctrl+X. 화면의 ^는 Ctrl을 뜻한다. 새 파일은 저장할 때 파일로 기록된다.

vi 모드와 기본 조작

기반: 학습지 3–4쪽 / 중간평가 예상문제 13–15

시작은 일반 모드다. i는 커서 앞, a는 커서 뒤에 입력을 시작한다. Esc로 일반 모드로 돌아간다. h/j/k/l은 왼쪽/아래/위/오른쪽, x는 문자 삭제, dd는 한 줄 삭제, 3dd는 세 줄 삭제, yy는 한 줄 복사, p는 줄 단위 복사 시 아래에 붙여넣기다.

vi 저장·검색·치환

기반: 학습지 3–4쪽 / 중간평가 예상문제 13–15

:w 저장 / :wq 저장 후 종료 / :q! 미저장 변경을 버리고 종료 / :set number 줄 번호 표시 / /Linux 뒤 Enter는 검색 / :%s/Linux/Ubuntu/g는 전체 줄에서 각 줄의 모든 일치 문자열을 치환한다. %는 전체 줄, g는 한 줄 안의 모든 일치다.

04 종료·콘솔·부팅·서비스

종료 범위

기반: 학습지 1–2쪽 / 종료 명령 문제 / 중간평가 예상문제 11–12, 23

sudo poweroff는 시스템 전원 종료, sudo reboot는 시스템 재부팅이다. exit는 현재 셸 종료, logout은 로그인 셸 로그아웃이다. sudo는 허용된 명령을 지정 사용자 권한으로 실행하며 기본 대상은 root다. 터미널 셸 종료와 데스크톱 전체 로그아웃은 구분한다.

shutdown 옵션과 시간

기반: 학습지 1–2쪽 / 종료 명령 문제 / 중간평가 예상문제 11–12, 23

sudo shutdown -P now 전원 종료 / -r now 재부팅 / -P +10 10분 뒤 전원 종료 / -r 22:00 지정 시각 재부팅 / -c 예약 취소 / -k +15 종료 없이 경고 메시지만 전달. +N은 N분 뒤, now는 즉시다.

가상 콘솔

기반: 학습지 1–2쪽 / 종료 명령 문제 / 중간평가 예상문제 11–12, 23

가상 콘솔은 하나의 OS에서 여러 로그인 화면을 제공한다. Ctrl+Alt+F3은 일반적인 텍스트 콘솔 전환 예, sudo chvt 3도 콘솔 전환이다. GUI 복귀 키는 환경별로 다르다. tty는 현재 터미널 장치, who는 로그인 세션 목록이다. 화면 전환만으로 세션이 끝나지 않는다.

지금 상태와 다음 부팅

기반: 학습지 1–2쪽 / 종료 명령 문제 / 중간평가 예상문제 11–12, 23

systemctl get-default는 기본 부팅 target을 확인한다. sudo systemctl isolate multi-user.target은 지금 전환, sudo systemctl set-default graphical.target은 기본 부팅 target 지정이다. 0↔poweroff, 1↔rescue, 3↔multi-user, 5↔graphical, 6↔reboot의 전통적 대응을 학습한다. 숫자 런레벨은 배포판별 차이가 있다.

시작과 자동 시작

기반: 학습지 1–2쪽 / 종료 명령 문제 / 중간평가 예상문제 11–12, 23

systemctl start는 지금 시작, enable은 부팅 자동 시작 설정이다. enable --now는 둘을 함께 한다. sudo systemctl enable --now openbsd-inetd는 사진의 서비스 예시이며, 해당 서비스가 설치된 수업 환경을 전제로 한다.

05 네트워크 명령·주소

주소·경로·이름을 구분

기반: 기본 네트워크 문제 / 중간평가 예상문제 16–20

ip addr는 인터페이스와 IP 주소, ip route는 라우팅 경로와 기본 게이트웨이, nslookup은 DNS 조회다. 게이트웨이는 다른 네트워크로 나가는 통로이고 DNS는 도메인 이름 등의 레코드를 조회하는 체계다.

횟수를 바꿔 해석

기반: 기본 네트워크 문제 / 중간평가 예상문제 16–20

ping -c 4 192.168.111.2에서 -c 4는 ICMP Echo 요청 횟수다. 4를 10으로 바꾸면 전송 횟수가 증가한다. IP 주소나 네트워크 속도가 커지는 의미는 아니다. 응답 수·왕복 시간은 관측 결과이며 보낸 횟수와 구분한다.

주소 설정 용어

기반: 기본 네트워크 문제 / 중간평가 예상문제 16–20

IP 주소는 인터페이스의 네트워크 주소, 넷마스크는 네트워크 부분과 호스트 부분의 경계다. 255.255.255.0은 /24다. DHCP는 주소 등 설정을 자동으로 제공한다. 정적 설정은 직접 값을 지정한다. DHCP가 매번 다른 주소를 준다고 단정하지 않는다.

환경별 명령

기반: 기본 네트워크 문제 / 중간평가 예상문제 16–20

Linux: ip addr, ip route, 설치된 환경의 ifconfig. Windows: ipconfig /all. nm-connection-editor는 NetworkManager 연결 설정 GUI다. 사진의 Windows 출력 제외 항목처럼 답이 모호한 문항은 명확한 기능 비교로 바꾸었다.

06 Telnet·SSH·SCP

기본 포트와 암호화

기반: 중간평가 예상문제 21–25 / 수업 노트의 원격 접속·파일 전송 예시

기본 TCP 포트는 Telnet 23, SSH 22다. Telnet은 일반적인 접속에서 평문으로 통신하며 SSH는 암호화한다. 포트 번호는 설정으로 바뀔 수 있으므로 문제에서는 기본값을 전제로 한다.

원격 로그인

기반: 중간평가 예상문제 21–25 / 수업 노트의 원격 접속·파일 전송 예시

ssh student@192.168.111.140에서 student는 원격 계정, @ 뒤는 서버 주소다. 접속 이후 whoami, hostname, pwd는 원격 셸에서 실행된다. 원격 셸의 exit는 그 셸 세션을 끝낸다.

전송 방향

기반: 중간평가 예상문제 21–25 / 수업 노트의 원격 접속·파일 전송 예시

scp test.txt student@192.168.111.140:/home/student/는 로컬 → 원격이다. scp student@192.168.111.140:/home/student/a.txt .는 원격 → 로컬 현재 디렉터리다. scp의 인수 순서는 원본, 목적지다. 콜론 앞은 원격 접속 대상, 뒤는 원격 경로다.

명령 선택

기반: 중간평가 예상문제 21–25 / 수업 노트의 원격 접속·파일 전송 예시

원격 셸 작업은 ssh, SSH를 이용한 파일 복사는 scp, 로컬 복사는 cp다. scp는 파일을 복사하므로 원본 파일을 남긴다. 로그인과 복사를 서로 바꾸어 외우지 않는다.
