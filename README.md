# 시험노트 2026

여러 과목을 모아 보는 반응형 시험 대비 사이트입니다. 콘텐츠 프로그래밍(Unity 6000.3.23f1, Input System)과 컴퓨터비전(1–7장)을 제공합니다.

컴퓨터비전은 개념·입출력 정리, 비교표, 모델 흐름 13개, 설정값과 지표 변화 해석, 계산 풀이 14개, 예상 문제 32개를 포함합니다. 패치·토큰 수 및 합성곱 출력 계산기로 값을 바꿔 볼 수 있습니다. 검색, 모바일 접이식 목차, 정답 일괄 펼치기, 인쇄 시 풀이 포함을 지원합니다.

## 화면 구성

- 홈: 과목 카드, 과목 검색, 이 브라우저에서 마지막으로 본 과목 링크
- PC 과목 페이지: 왼쪽에 개념 / 스크립트 / 복습 그룹별 접이식 목차
- 모바일 과목 페이지: 상단의 목차를 눌러 펼치기, 항목을 선택하면 자동으로 접기
- 정리 검색, 전체 코드, 암기표, 예상 문제와 정답 펼치기

## 로컬 실행

Node.js 24 LTS 사용. 외부 런타임 의존성이 없습니다.

```sh
npm start
```

http://localhost:5000 에 접속합니다. `npm test`로 HTTP 응답과 공개 파일 범위를 검사합니다.

## Heroku 배포

이 저장소에는 배포를 위한 설정만 포함합니다.

1. Heroku 앱의 Deploy 탭에서 GitHub 저장소를 연결합니다.
2. 배포할 브랜치를 선택하고 Deploy Branch를 실행합니다.
3. `web` 프로세스가 실행 중인지 확인합니다.

루트 `package.json`으로 Node.js 앱을 인식하며, `Procfile`의 `web: npm start`로 실행합니다. 서버는 Heroku의 `PORT`에 바인딩합니다. 별도 빌드나 DB, 환경변수 입력은 필요하지 않습니다. 자동 배포를 켜면 이후 push가 배포를 유발하므로 원하는 경우에만 켜세요.

## 과목 추가

1. `public/subjects/<과목-id>/index.html`에 과목 페이지를 만듭니다.
2. `public/subjects.json` 배열에 다음 형식의 항목을 추가합니다.

```json
{
  "id": "subject-id",
  "title": "과목 이름",
  "subtitle": "학습 범위",
  "description": "과목 소개",
  "href": "/subjects/subject-id/",
  "tags": ["핵심 정리", "예상 문제"]
}
```

홈의 카드와 검색은 과목 목록에 따라 자동으로 갱신됩니다. 홈 HTML의 기본 유니티 카드는 JavaScript나 목록 로딩 실패 시에도 열 수 있는 대체 링크입니다.

## 자료와 검증 범위

유니티 강의자료 1–4와 컴퓨터비전 강의자료 3권(1–5장 41쪽, 6장 32쪽, 7장 25쪽)의 학습 정리를 기반으로 합니다. 원본 PDF나 사용자 컴퓨터 경로는 배포 파일에 포함하지 않습니다. 입력 코드는 신형 Input System 기준이며, Unity 에디터에서 직접 컴파일·실행한 상태는 아닙니다. 페이지 하단에 참고 자료와 범위를 안내합니다. 컴퓨터비전 계산 예시와 상황형 문제 일부는 학습용 보충입니다.

로그인 기능은 없습니다. 배포된 주소에 접근 가능한 사람은 학습 내용을 열람할 수 있습니다. 학습 데이터는 서버에 저장하지 않으며 최근 과목 ID만 해당 브라우저의 localStorage에 기록합니다.
